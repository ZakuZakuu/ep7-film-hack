# Safety and security

This is experimental research involving a physical camera, not a product or camera firmware update service. Please do not install or test modified firmware on your only camera based solely on a GitHub patch, checksum, synthetic test, or apparent file similarity.

Report reproducible risks privately to the maintainers before submitting potentially dangerous instructions or device identifiers in a public issue. Do not disclose serial numbers, MAC addresses, SSIDs, personally identifiable camera captures, device dumps, original OEM firmware or private photographs.

Any physical camera test requires a separately reviewed device-specific plan and explicit owner consent. Read [docs/06-validation-and-safety.md](docs/06-validation-and-safety.md).
