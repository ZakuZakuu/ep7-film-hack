**Decision: pivot toward stock shooting workflows and continue a small usability/recipe-observability experiment; keep firmware modification, automatic upload and arbitrary ART unlocking paused.** The owner wants pleasing Ricoh/Fujifilm-inspired JPEGs and convenient saved looks, with no required LUT format or specific mode family. ## Two real stock workflows, with honest recall scope

These are documented steps, not operations executed on the owner's camera. No fabricated film recipe values are supplied.

**W1 · Small COLOR/MONO shooting library.** In P/A/S/M, move the front profile-control switch to COLOR/MONO. On its screen, use up/down to highlight Profile, then left/right or the rear dial to select COLOR1–4/MONO1–4; set applicable controls and confirm with OK. They save to that slot. Later press the **u shortcut** to reopen the profile screen, highlight Profile if necessary, select the wanted slot and confirm. For monochrome grain/tint/sharpness/contrast, use the relevant LV super-control fields. Holding OK at the profile entry resets its parameters, so it is not a “save” shortcut. Sources pp46–53/107.

Useful value: reuse adjusted slots with no repeated twelve-slider entry, shading/tone changes or parameter recreation. Switching between the profile position and the normal switch position selects the two processing contexts, but is **not** a documented full-configuration restore. **WB, WB shifts, exposure/ISO/AF and other global state still need verification/re-entry** when recipes differ. Start with styles sharing a deliberate WB policy if that tradeoff is acceptable; this is a design proposal, not measured quality.

**W2 · Normal modes plus a separately adjusted Custom or ART look.** With the profile switch in its normal position and mode dial in P/A/S/M, set Natural/Muted/Portrait/Vivid or K Custom through **OK→Picture Mode→selection→OK**. Configure eligible parameters once; per-mode storage is documented. Reopen that field to select another adjusted identity. Eligible ART Picture Mode entries provide a route to an ART look while retaining the chosen exposure mode; press INFO for the five eligible Fine-Tuning sliders. This avoids assuming ART must always use the top ART dial. Sources pp103–106/130.

If OK shows Live Control instead of the LV super control panel, choose the desired control display for that shooting mode under **Custom Menu→Disp/PC→K Control Settings** (p146), or use the documented Live Control selector (p91). The last-used field is highlighted (p90), reducing navigation if left on Picture Mode. No measured tap-time or fixed number of button presses is claimed. The documented AEL/AFL/movie-button roles **do not include Picture Mode, arbitrary preset recall or Multi Function** (pp112–113; E-P7 Q&A); do not borrow that shortcut from another camera.

**Critical inconvenience: there is no verified atomic recall of the entire recipe, particularly style plus WB/shift and global controls.** WB compensation is chosen for a WB option (p96), and four one-touch WB memories survive power-off (p95); they are not documented as automatic per-style WB bindings. A warm-Muted recipe and a cool-COLOR recipe therefore cannot be promised one-action complete switching. Likewise two different saved variants of the **same** ART family are not established independent user slots.

### Minimum human-readable recipe record

Record an owner label, base family and exact variant/slot, its adjustable picture/profile/effect fields, Fine-Tuning/Partial Color where applicable, **WB mode or CWB/one-touch identity plus A–B/G–M shifts and Keep Warm policy**, exposure mode/compensation and ISO policy, noise filter/reduction, color space and RAW+JPEG choice. Separate fields that the chosen slot saves from fields that must be set globally. Record unsupported options and the MONO-grain preview exception. A saved WB measurement/automatic exposure result cannot be regenerated from a label or a single capture's number alone.

This is a **manual checklist/shareable text convention** for future review, not an import file, camera-ready payload, unlimited firmware library or UI project. Optical hardware, if used, must also be recorded because JPEG metadata need not identify it. Defaults/full reset (p129), profile reset (pp50/53) and photographic recipe restoration are different operations.

Conversely an attractive manually entered look is not evidence of a one-click library, and stock capabilities do not establish equal Ricoh/Fujifilm rendering. **Pivot/continue R1; pause R2/R3 and unguided firmware traversal.** G2 here remains the gate for new binary engineering, not a reason to deny documented stock camera functions. G3 visual expressivity and G6 actual-camera usability still need evidence; MONO grain makes full live-preview equivalence unavailable for that documented effect.

## Highest-value next experiment and stop condition

**One separately chosen stock-only recall audit, not a calibration campaign:** choose two existing desired stored looks with one known per-mode difference and different WB/shift needs. Record the few relevant GUI values, select A→B→A through the documented shortcut, and check which fields return; if chosen, repeat after power-off. Up to three/four original RAW+JPEG captures may supply selected metadata checks. Compare the GUI's WB/shift/effect values to specific fields; missing/ambiguous fields stay unknown. Record actual navigation effort and whether the saved looks are useful to the owner. **Requires separate camera-operation authorization; not run in this task.** No debug/PTP/Wi-Fi command, setting-file write, invented profile or image-quality promise.

This discriminates the useful stored-style subset from the full-state UX gap with minimal work. If required global controls always need manual recall and that effort is unacceptable, **stop R1 rather than build a pretend preset manager**. If a small fixed-WB style set is useful, continue that stock workflow without making external import a prerequisite. Automatic loading resumes only with exact-model supported transport/storage evidence. ART unlocking resumes only with a real compatible operator/parameter and safe installation/recovery path, not another log/string match.
