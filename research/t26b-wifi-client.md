# T26b · EP71 电脑端 Wi-Fi 配方工具

客户端已能按 T25 的 EP71 合同读取、备份、逐值写入、完整回读及还原配方。
非法配方在创建传输对象前拒绝，dry-run 完全离线；白平衡和曝光建议只打印。
超时、断连或回读不一致时停止写入并保留本地拦截标记，不自动重试或回滚。
目前只有回环模拟证据，没有连接相机或声称真实非易失保存成功。

**做了什么**

- 从 T25 / PR #67 提交 `345ca50` 继续，严格绑定[正式 EP71 协议](../docs/wifi-recipe-protocol.md)，未改任何固件、补丁、清单或预期哈希。
- 原创标准库 CLI，直接复用 Recipe Studio 的完整校验；按轮盘/物理索引及已核实的高/中/低键映射 40 个值，能力不符禁止写入。
- 写前请求原厂 rec 会话、保存用户目录备份和本地意图；只写差异，完整回读。加入持久不确定状态、本地进程锁及显式手动重连确认。
- 原创独立 ID 表的回环 HTTP 模拟器与测试；模拟器不加载原厂数据，不实现固件执行、ISP、NVS 或 raw writer。

**结果**

| 场景 | 可复现结果 |
| --- | --- |
| 正常写入/还原 | 完整 40 值相同；独立验证轮盘橙色到物理 6、COLOR4 阴影/高光及暗角键；其他三槽不变，备份可还原。 |
| 原厂/错误版本/机型 | 能力或机型检查拒绝；未请求 rec，未发标记写入。标识不是固件真实性证明。 |
| 非法输入/dry-run | 复用同一校验，重复字段、类型与范围错误拒绝；dry-run 不创建状态、不建 socket。 |
| 中途中断/超时 | 已应用但缺回复时不补发；尽力读取实际值，保留拦截标记，后续写入被拒绝。 |
| 回读不同 | 完整核对发现不同后报告不确定，不发送回滚值。手动重连确认只读后解除标记，不自动重做。 |
| 本地/网络边界 | 公网、域名、链路本地及组播拒绝；不跟随 HTTP 跳转；备份失败/已有锁先于首个标记写入，损坏状态保留。 |
| 隐私 | 仅提取型号；忽略序列号/MAC 字段，不记录原响应；配方和状态默认在用户目录，禁止写进本仓库。 |

运行方式及 Windows/macOS/WSL 操作见 [CLI README](../tools/ep7_wifi/README.md)。`python3 -m unittest discover -s tests -p test_ep7_wifi.py -v` 在本地回环通过 17 项；新增 Python 3.12 的 Windows/macOS/Ubuntu CI。完整测试只需标准库；原厂链路证据属于 T25，不能由本模拟器替代。

**风险与未知**

- 请求成功及当前回读不证明真实断电持久性；没有相机侧 40 值原子性或队列取消保证。迟到写入即使在一次回读后才发生，也仍需机主重新连接并核对。
- 本地锁不协调相机菜单或其他 App；强制终止可能留下锁/意图。模型不证明真实 rec 准入、无线稳定性、跨核缓存或 Myset 行为。
- 50 ms 请求间隔是上游经验，不是 E-P7 实测时限；范围、型号及能力字段按 EP71 严格拒绝，不做猜测兼容或静默补零。
