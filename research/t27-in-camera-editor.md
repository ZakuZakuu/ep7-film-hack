# T27：机内 H/L 编辑器地图与停止点

已定位 E-P7 四套 COLOR 编辑器的原生对象、数值枚举和提交入口。
原厂 S 控件会缓存自己的档位，增加 H/L 不能只替换一次读写。
删除键仍只是候选：局部控件没有改值，不代表上层界面没有使用它。
本轮交付可复现的界面地图和设计，未完成 v5，也没有可供 B5 安装的文件。

- 基线为已包含 PR #69 的 main；型号、完整哈希、地址、窗口摘要及实验结果见 [证据 JSON](t27-in-camera-editor-evidence.json)。
- 上游仅参考固定版本的 [PEN-F 编辑器设计](https://github.com/fishcu/oly_fw_analysis/blob/539fcf1fa9eda5fdef8ede4deeab94a4691d94c3/docs/color/pen-f/EDITOR.md) 与其配套文档；代码、地址均未移植。
- 重用现有 GNU 模拟器、T14 初始化区映射和 v4 设置夹具；未自建指令模拟器。

已验证与已定位：

| 部分 | 证据及边界 |
|---|---|
| 四套编辑器 | 描述表区分真正的复合编辑器与单项配置选择面板；原生工厂构建光标及颜色子控件 |
| 原厂 S 控件 | 四套工厂构造及 10 组步进通过；属性查询和枚举转换执行原厂代码；重置停在默认值查询入口 |
| 提交 | 重放至原生提交分支；静态引用另定位 GUI 设置接口，其忙状态检查和协调调用不能绕开 |
| 删除键 | 已定位按下、释放、长按编号及局部分派；事件队列整理也必须保留，上层按键状态机未闭合 |
| 显示 | 已定位光标与 S 数值的独立显示查表；尚未证明色轮多边形的数据生产者及轴标签绘制入口 |
| 排除误接 | 邻近 C3d 接口按半字访问短结构，未证明与十二色键的关系，不能当成色轮已接通 |
| v4 互通 | 机主 B4 已证明现有 Wi-Fi、持久化和成像路径；本轮没有证明机内 H/L 编辑能进入该路径 |

设计建议（尚未实现，不是补丁承诺）：

1. 仅在真正的 COLOR 复合编辑器实例内启用独立的轴状态；进入默认 S，退出清除，不改变原厂对象布局。
2. 轴切换须重新生成所有颜色子控件的枚举、当前索引及显示；H/L 使用各自范围，S 完整保留原厂分支。
3. 读取复用 v4 校验格式；写入须保留 GUI 准入，再进入原厂应用设置机制及 v4 发布点。不能直接把大整数标记塞进 S 枚举，也不能在 GUI 线程直接调用存储函数。
4. 优先在 H/L 禁用 ALL 和长按 OK 重置；必须在计时事件和首次写入之前拦截，短按退出仍保留。未闭合这些路由前不发布实现。
5. 数值、色轮和轴标签必须同时反映当前轴；只改数字不算完成。尚不修改任何 OSD 组件。
6. 新状态与指针按自然对齐分配，代码位置、生命周期及 ABI 另行证明；原厂布局不插字段。候选布局见 JSON，尚未指定固件地址。

停止依据：

- 按键检查采用两种有界方法：原生局部控件分派重放，以及事件名表、通用分派和上层状态线索核对。后者未取得拍摄时 COLOR 界面的完整路由，不能确认空闲按键；RAW 编辑状态不冒充拍摄状态。
- 显示检查采用数值消费者和邻近 C3d 接口两条入口；取得数值映射并排除误接，未取得真正色轮消费者。不扩展无锚点扫描。
- 因此按 Issue 允许的降级交付停止；没有新增补丁、预期 v5 哈希或机内 H/L → ISP 成功结论。

复现（需要机主私有的、哈希一致的原厂文件；所有输出保留在私有目录）：

```sh
bash tools/setup_t20_environment.sh
python3 tools/ep7_t27_editor_probe.py --upstream work/upstream/oly_fw_analysis \
  --stock /tmp/ep7-stock/E142_EP7_firmware_download.BIN --out /tmp/ep7-t27-check
```

工具完整保存私有执行记录；公开 JSON 只保留语义摘要、地址与摘要哈希。
诊断、分配、计时和局部上下文查询是明确模型，未建模访问停止；设置元数据及控件算法由原厂代码执行。
提交服务准备、默认值查询与队列整理均保留明确停止点，没有把局部重放写成完整事件链。
对齐审计覆盖实际执行的主程序数据访问；不把夹具通过当成尚不存在的 v5 ABI 验证。
旧版本仅核对预期包哈希，不生成安装文件；原始文件、解码数据、清单和机器码均未提交。

B5 预案仅在未来 v5 通过离线验收后生效，本轮不要据此刷机：

- 检查进入、退出、忙状态、三个轴和轴标签；单色区上下键与拨盘、上下限、ALL 和长按 OK。
- 机内改 H/L 后用既有 Wi-Fi 工具读取；Wi-Fi 写入后返回编辑器核对，再检查重启保持。
- 核对 S 与其他菜单、取景、回看和 JPEG；异常立即停止，由机主选择退回已验证 v4 或原厂。

建议先审查本地图；下一步只解决拍摄时编辑器的上层按键路由和实际色轮绘制源，再决定是否实施 v5。
