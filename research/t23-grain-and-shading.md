# T23 · E-P7 颗粒与暗角处理链

彩色颗粒属于**有条件可行**：原厂已有可复用的处理工序，但目前不能靠打开一个参数就得到可靠的彩色颗粒照片。
普通暗角的强度与形状调整已有明确入口；高光保护还需要从处理后的照片生成亮度遮罩，不能只替换一张曲线表。
本轮跑通了原厂的工序构建与参数上传，发现 E-P7 的设置键、遮罩格式和内存需求与 PEN-F 有实质差异。
这些结果证明的是离线配置能力，尚未证明实拍效果、彩色输出、实时预览或真机内存余量。

**做了什么**

- 基于指定 main，复用固定版本的上游文档、GNU 模拟器和已有验证器；新增的是固定入口的原创离线探针，没有新建模拟器或扫描框架。
- 映射设置 → 参数 → 请求 → 组合器 → ISP 寄存器；执行 COLOR、普通 MONO、替代 MONO、颗粒关闭及较小尺寸的原生工序构建。
- 对照真实 PEN-F 参考固件，核对颗粒遮罩和暗角曲线；执行暗角遮罩生成、两类请求回调、双寄存器组上传及自定义亮度表上传。
- ART 仅核对 Grainy Film 两个既有标识的组合器选择，没有继续追踪 ART 调用链。地址、哈希、模型边界和对照均在[证据 JSON](t23-grain-and-shading-evidence.json)。

**结果**

| 问题 | 已验证事实及技术判断 |
| --- | --- |
| MONO 颗粒链 | 原厂参数构造和双组寄存器写入通过；普通与替代工序分别使用不同组合器及两套增益。颗粒遮罩与参考固件逐字节相同。 |
| 工序与缓冲区 | 指定夹具下 COLOR 为一道主请求；普通 MONO 为遮罩 → 原图显影加颗粒 → 暗角 → JPEG 输出。后三步并非把遮罩当照片显影。 |
| 内存 | 全尺寸普通 MONO 的三项中间分配合计约 102.5 MiB；替代路径省掉颗粒遮罩。只是原生申请量，分配成功与提交接受均为模型，不能据此说 COLOR 余量足够。 |
| 彩色颗粒的完整路线 | 需要增加遮罩与中间图像工序，复用已有列表和回调，同时保留 COLOR 的矩阵、色调与 HSL 身份，并另行分派颗粒。已测原生刷新路径把 COLOR 的颗粒有效设置置零，颗粒组合器与专用遮罩曲线也不由 COLOR 自动选中。 |
| 强制单色 | 已验证格式相关的包装器会忽略 COLOR 身份而写入单色控制字。它用于遮罩可以合理；若把彩色照片误送入它则有失色风险。必须分开验证遮罩路线与照片路线，不能全局把模式改成 MONO。 |
| 不另做颗粒遮罩 | 原厂存在不申请该遮罩的替代 MONO 工序，是更省内存的候选；它不等于“原厂 COLOR 主请求已经支持”。COLOR 的暗角与颗粒还争用同一个组合器配置位置，需要分开处理或先关闭暗角。 |
| 颗粒粗细 | 已定位强度和种子来源，没有发现经过验证的独立颗粒半径控制。缩放、种子或提高强度不能冒充原生粗细参数。 |
| Grainy Film | 两个既有标识选择的组合器均不同于 MONO 颗粒组合器。共享配置构造模块不能证明共享完整颗粒算法，不能用它宣称彩色颗粒已成立。 |
| COLOR 暗角链 | 设置来源、有效值、请求字段、系数选择、双轴缩放及组合器已关联；真实原厂函数生成了对称的暗角遮罩，原始曲线与参考固件相同。 |

暗角扩展的最小改动与风险：

- **重调现有强度档：有条件可行，优先级最高。** 保留现有档数、调整空间系数，改动面比新增档位小；扩大可选档数还要修改回调范围和分支表，并核实设置、预览及 RAW 元数据约束。空间缩放不等于改变混合浓度，也不保证视觉更自然。
- **只调形状或曲线：有条件可行。** 保留原生遮罩尺寸及曲线长度，调整径向曲线或其坐标生成；固定网格、插值、量化和硬件采样可能带来色带与不连续，不能直接把桌面曲线视为机内等效。
- **高光保护：配置条件部分成立，完整路线未成立。** 原厂有向黑、向白混合的配置，原生上传器接受自定义的亮度表；两次混合的数学设计来自上游，E-P7 的像素运算尚未验证。必须取得已经过色调处理的亮度，再安排额外遮罩、请求、依赖和清理；早期颗粒遮罩的输入域不符合这一条件。

**风险与未知**

- 尺寸查询、设置见证值、分配成功、请求接受和无争用锁有明确模型；没有运行 ISP 像素、JPEG 编码、RTOS 完成中断或全相机启动。工序是显式输入夹具下的结果，未复现拍摄上游全部准备和零效果优化。
- 真机内存预算、异步失败/取消/清理、缓存一致性及彩色颗粒的实际通道行为仍未知；原厂替代工序标志的用户含义也未确定，不能称为预览模式。
- 没有修改原厂代码、T20 补丁或预期哈希，没有生成新固件或连接相机。原厂数据、派生清单与捕获均留在私有 `/tmp`。

**需要机主决定的事**

建议审查后再决定下一项实验：若优先颗粒，先限定为不生成固件的 COLOR 替代工序设计审查，验证参数来源、颜色控制、暗角冲突与分配失败处理；若优先较快改善照片观感，先选择暗角强度/形状重调。
高光保护暂不作为最小实现目标。本任务提交一个 PR 后停止，不启动 T24。

复现：先执行现有环境初始化，再按证据 JSON 的命令运行[离线探针](../tools/ep7_t23_probe.py)。只提交脱敏结果，探针输出目录必须位于私有 `/tmp`。
