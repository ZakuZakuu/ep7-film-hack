# E-P7 1.1 最小 COLOR H/L 实验

仅固定两项：黄色关联色区 H 滑块单位 +3（原生 −3000），蓝色关联色区 L 滑块单位 −5（原生 −200）。色区名称及单位参考 [fishcu 的固定研究](https://github.com/fishcu/oly_fw_analysis/tree/539fcf1fa9eda5fdef8ede4deeab94a4691d94c3)，实际 E-P7 颜色由实拍确认。没有新增菜单或存储；这组数值用于使正常 COLOR 构造路径的变化明显，不是完成的胶片配方。

原创 `hook.s` 取代 `0x603b02d9` 的 5 字节调用，在加载段 2 的 `0x6055e5f0` 放置 44 字节代码，再回到 `0x603b02de`。仅原厂 COLOR 构造分支进入挂钩。保存原厂输出，不改变饱和度、LUT 或其他记录；详细条件见[研究报告](../../../research/t20-ep7-hsl-min.md)和[选定验证](../../../research/t20-ep7-hsl-validation.json)。这些是 CPU 参数及写入窗口的模拟证据，不是 JPEG 或安全恢复验证。

## S2/S3 约定与结构

PEN-F 参考源码在 `0x604f7506` 接管原厂 COLOR 调用，执行 96 字节调用帧的构造器后回到 `0x604f750b`，保存后处理借用的寄存器，避免额外 CALL 改变 MDR。本轮没有 PEN-F 原厂输入；这是上游源码/文档约定。E-P7 的对应调用和返回分别通过真实代码核实为 `0x603b02d9` / `0x603b02de`。本实现后处理只借用 D0/A0 和 8 字节临时栈；不增加 CALL 或硬件循环，SP 立即数加法与 MOV 在使用的 GNU 语义中不改 PSW。实际地址矩阵比较全部 32 个模型寄存器、上下文及有效栈，释放的临时栈内容允许变化。

E-P7 原始表每记录 28 字节；输出从对象 +688 开始，为 12 条各 24 字节记录，H/S/L 半字在记录内 +18/+20/+22，控制字在对象 +976。请求的 12 个饱和输入从 +1816 读取。轮盘零基索引 i 对应物理记录 `(i % 2) * 6 + i // 2`；物理记录顺序因此对应轮盘第 1、3、5、7、9、11、2、4、6、8、10、12 区。用颜色作近似描述，就是黄、红、洋红、蓝、青、绿、橙、玫红、紫、浅蓝、青绿、黄绿，不能当成普通 RGB 色相的严格区间。

H 的参考换算为 `H_native = -1000 * H_slider`。L 的滑块值 −7 至 +7 依次映射到原生值 `[-300, -250, -200, -150, -100, -50, -25, 0, 25, 50, 100, 150, 200, 250, 300]`。本补丁仅用上述 +3 / −5 两点，不增加可编辑范围。

E-P7 的公开模式号 54/55/56/64 由 `0x60460458` 表分派到四个原生配置读取分支；12 个饱和键分别从 927/939/951/1655 起连续读取。处理选择器合成键为 11 时进入共享 COLOR 构造器。测试使用四分支的默认饱和输入，未执行完整设置保存或整机请求创建；本轮没有实现存储或切换功能。

## 环境与本地构建

Linux / WSL、Python 3.12、Git、curl、tar、make、C/C++ 编译环境及 GNU 构建依赖。Cloud 现有 Setup 可以保留，并追加以下两行；也可单独用此 T20 入口安装所需工具。脚本只获取公共工具，不下载固件、不读取序列号、不连接相机：

```sh
cd /workspace/ep7-film-hack
bash tools/setup_t20_environment.sh
```

上游始终固定在 `539fcf1`，只在忽略目录运行。GNU 动态归档先与 Sourceware 的精确提交及完整树比较；`git add -f -A` 纳入源码原本跟踪的忽略文件。包装器另外校验两个原始核心文件，再运行上游 strict 准备器和 runner 构建；不修改上游构建器，不制作 `.penf-source.json`。实际与文档中的归档哈希都记入外部构建清单。

机主以自己取得的原厂文件运行，`--out` 必须是新目录且位于仓库之外；Cloud 中只能用私有 `/tmp`。构建器校验完整输入、源码、两个原始修改范围、汇编结果及整个输出的固定哈希，再修复主组件校验和、重解析五组件。输出为完整包，其他四组件保持逐字节一致：

```sh
umask 077
python3 patches/hsl-min/e-p7/build.py \
  --upstream work/upstream/oly_fw_analysis \
  --stock /tmp/ep7-t20/catalog/OLY_E_142_1100_0000_0000.BIN \
  --out /tmp/ep7-hl-local-build
```

- 测试包：`install/DCOLYMP/E1429999.BIN`，SHA-256 `d0fa93e752ec2680910dfabfef50cfc2ffb510aa8c8ec49cf6177868037bec8e`。
- 原厂恢复文件：`restore-stock/DCOLYMP/E1429999.BIN`，SHA-256 `9d1610124ad98f6edae4540182205f06c9c703d9033ef0c4f19847193f95eaeb`，与原厂输入逐字节相同。
- 两者均为 111017984 bytes，内部版本均保持 1.1；不能靠版本显示区分。源码/工具变更后构建失败时，应重新验证，而不是删除哈希保护。目录和 BIN 不得上传 GitHub。
