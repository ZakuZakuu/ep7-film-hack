# 01｜产品目标和验收约束

## 用户痛点（高优先级）

用户已有 Olympus PEN E-P7，希望拍出接近理光或富士胶片模拟的满意照片。当前预设、切换方式和效果组合不满意；完整配方保存/召回不方便，是与色彩表达同等重要的问题。原生能力是否足够获得目标风格仍须实证，不能先宣称必须改固件。2026-10-12 的 Issue #29 与用户补充允许复用 Picture Mode、K Custom、COLOR/MONO、ART 或其他有依据的路径，不要求某种 LUT 格式或指定引擎。

## 北极星体验

- 在 E-P7 相机上直接选择一组「复古负片」「暖色金片」「低饱和电影色」「经典黑白」等**自建**风格。
- 使用相机已有的 Picture Mode、K Custom、COLOR/MONO、ART 或其他自然入口快速切换，**不限定 ART/COLOR/LUT**；如某项效果不能实时预览，必须明确告知，不能承诺完整所见即所得。
- 直接得到受风格影响的 JPEG；保留 RAW+JPEG 选项，方便回退。
- 跨光照/室内外/肤色表现稳定；不以单张网图“相似”当成成功。
- 优先减少保存与切换时反复手工操作；导入/导出、完整召回和命名库仍是期望功能，不能无证据宣称可用。小规模原生风格库可以作为实用的阶段方案来验证，但“手动配方”不等于自动导入。成像效果与使用便利性共同决定路线是否值得继续。

## 候选策略（按证据和体验排序，而非锁死 ART）

1. 先核验各原生模式能表达什么、保存哪些参数、怎样最快选择；区分局部风格与包含 WB/曝光等全局状态的完整配置。见 [T9 能力与工作流](../research/e142-native-style-workflows.md)。新二进制工程仍需要**选择→参数记录→真实预览/JPEG 消费**链证据。
2. 如果原生 12 色饱和度、明暗和暗角自由度不够，调查已验证的颜色矩阵、曲线、ISP 参数或可以扩展的原生处理组合，再评估导入、插槽扩展与命名。
3. 只有在原生路径不合适、并已有具体代码/资源和可靠恢复证据时，才考虑替换 ART、添加新处理模块或完整固件修改。无法自动导入的原生方案要如实标注人工步骤与容量；不能为了交付开发没有相机功能支撑的 UI。

**先证明色彩确实参与相机的实时预览和 JPEG 管线，再开发漂亮的风格编辑界面。** 找到菜单文字或媒体素材不等于找到成像效果。

## 三级里程碑

- **M0｜可研究性**：取得可靠 E-P7 固件样本（若可以）；记录型号、版本、SHA-256、来源；成功识别至少一种有证据的容器/段结构，或说明阻塞。
- **M1｜原生可用性与扩展门槛**：先核验现有参数、保存与选择流程，再评估它们是否能承载目标风格；需要新二进制功能时，仍必须追踪到真实参数记录和处理消费者。文档支持不冒充实机验收，原生手工工作流不冒充导入。
- **M2｜产品验证（远期）**：有安全验证条件后，任意两个自建风格可从相机自身入口切换，所见/所得 JPEG 符合定义，未破坏基本拍摄。

## 约束

- 不以视频、RAW 内嵌预览或手机套滤镜冒充机内 JPEG 直出。
- 各类 LUT 需声明输入色彩空间、输出色彩空间、gamma 与白平衡条件。
- 3D LUT 只能控制颜色映射，不直接提供颗粒、Halation、光晕等空间效应。
- 他人品牌风格仅用于视觉研究；名称注明 *inspired*，不声称等同原厂配方或使用受限资产。

## 明确排除（第一轮）

相机 UI 重制、手机商业 App、品牌预设商店、批量造几十款配方、实时视频滤镜、无恢复条件的实机刷机。
