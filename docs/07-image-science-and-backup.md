# 07｜胶片模拟成像科学与可交付备选

## 目标效果拆分

用户喜欢的「富士经典负片 / 柯达胶片」并非单个饱和度开关。可以拆成：

1. **基础成像**：传感器线性 RAW、黑电平/白平衡、去马赛克、降噪、锐化。
2. **色彩**：相机矩阵、色彩空间转换、3D LUT 或其他多维颜色映射。
3. **影调**：对比曲线、黑位、高光 roll-off、阴影层次、可能的亮度依赖色相/饱和度。
4. **质感**：随机颗粒、纹理相关、颜色/亮度依赖的颗粒强度。
5. **空间效果**：Halation（明亮边缘周围的色晕）、Bloom/柔光、暗角等。

只用 3D LUT 不可能完整产生 4、5 项。机内滤镜通常也包含清晰度/锐化/降噪差异。

## 先做可证伪的离线色彩实验

- 由相机拍摄 **自有版权** 场景，固定 WB/ISO/曝光，在 RAW+JPEG 下获得成对样本。
- 对色卡、自然肤色、绿叶、蓝天、钨丝灯/日光、低照明分别采样，覆盖不同光照和曝光。
- 用 RawTherapee/darktable 等可复现 RAW 处理获得标准基线，固定色彩空间后再加 LUT。
- 对预期风格构建 **复合效果**：tone curve + 颜色映射 + 颗粒/空间效果；用可重复参数记录每次结果。
- 对比同一套参数跨场景是否一致；观察白平衡变化、曝光过/欠导致的失败。
- 若在机内最终无法运行，还可保留为可用的 PC/手机自动化出片工具（但不把它称为机内直出）。

## 目标验证表

| 维度 | 验证问题 |
|---|---|
| 视觉 | 是否有用户喜欢的、明显区别于 E-P7 原厂 ART 的胶片风格？ |
| 稳定 | 室内人像/阴天/日照/夜景是否没有严重肤色崩坏或断阶？ |
| 相机集成 | 实时预览是否能看到接近保存的 JPEG？ |
| 切换 | 能否通过相机独立选择至少 2 个自建风格，且不逐项手调？ |
| 性能 | 连拍/拍照延迟和预览帧率是否有可接受损失？ |
| 回退 | 是否可保留 RAW、恢复原设置，不增加设备风险？ |

## 明确的成果分级

- **A：真正机内胶片模拟**：相机本身能拍出自定义 JPEG，并且用户能直接在机身切换；终极目标。
- **B：机内原厂算子组合**：突破 ART/COLOR 组合限制，但无法任意 LUT；有价值但局限需标注。
- **C：无刷机预设管理**：可以快速管理/写入原厂支持的配置；提升便利但色彩空间仍有限。
- **D：拍后自动处理**：相机产生原图、外部立即统一套风格；可以减少逐张修图，但**不等于机内预览/直出**。

不要因 A 的难度而悄悄把产品目标换成 D。必须明确给用户选择。
